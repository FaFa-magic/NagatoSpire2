# 长门鸟居卡框组合布局（2026-10-15）

## 结果

对长门普通攻击、技能、能力三种卡牌及白、蓝、金三种品质统一调整现有图片节点的显示布局，保留现有 PNG。竖向 PortraitBorder 外移后更多地压住红柱；上方 Banner 两端伸出柱子，形成完整鸟居横梁。卡图等比放大，接缝处有覆盖余量。

| 节点 | 调整 | 官方基础矩形 | 调整后显示尺寸 |
| --- | --- | --- | --- |
| Frame | 沿用上一轮横向 ×1.06 | 300×422 | 318×422 |
| PortraitBorder | 横向 ×1.14，高度不变 | 275×210 | 313.5×210 |
| Portrait | 两轴等比 ×1.10 | 250×190 | 275×209 |
| TitleBanner | 两轴等比 ×1.12 | 327×83 | 366.24×92.96 |

横幅比外框宽 48.24 个逻辑像素，约每侧外挑 24.12 像素。正文、类型牌的位置和字号沿用官方布局。先古卡采用其单独资源；普通布局会在节点切换到先古卡或其他角色时恢复。

## 渲染方式

只设置原有 TextureRect 的变换，补偿不同 Pivot，保持每个节点原来的中心。PNG、材质、资源绑定和节点数量不变，没有加入新的 Shader、描边、叠层或渲染步骤。图片显示面积增大所带来的像素处理量，对重新生成后显示为同样尺寸的素材同样存在。

卡图采用等比缩放，人物没有横向拉扁或拉宽。PortraitBorder 仅横向加宽，高度不变，因此底部横条仍与类型牌衔接。

生产实现：`NagatoSpire2Code/Patches/NagatoPatches.cs` 中 `UpdateToriiLayout`、`ApplyNodeLayout` 和 `OriginalTextureLayout`。布局始终从缓存的原始值计算，连续 Reload/UpdatePortrait/UpdateVisuals 不会累乘；原版蓝光仍由游戏控制。
