# 内框竖边各占柱子与卡图一半（2026-10-15）

根据实战截图反馈，上一轮所有内框统一横向 ×1.14 外扩过多。现在分别对三种外框校准竖边中心，使其位于柱子与卡图的交界。白、蓝、金三种品质使用对应类型的同一布局。

| 类型 | 内框横向比例 | 左竖边压住柱子的比例 | 右竖边压住柱子的比例 |
| --- | ---: | ---: | ---: |
| 攻击 | 1.034 | 51.8% | 50.9% |
| 技能 | 0.994 | 50.2% | 50.0% |
| 能力 | 1.009 | 49.2% | 50.9% |

覆盖比例由原生 Godot 对实际 PNG 的四段主要竖边高度采样得到，左右分别测量。三种品质合计九个组合均通过；卡图四边的覆盖检查也通过。内框高度、底部横条位置、卡图等比 ×1.10、横幅等比 ×1.12、外框横向 ×1.06 保持上一轮布局。

实现位于 `NagatoSpire2Code/Patches/NagatoPatches.cs`：三个类型常量及 `UpdateToriiLayout` 中的类型选择。继续使用原有 TextureRect 变换，没有新增绘制节点或 Shader；原版高亮不受修改。

本轮没有修改 PNG。先古卡仍使用自己的布局。比例基于原始布局计算，不会在刷新时累乘。
