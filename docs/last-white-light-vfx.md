# 最后的白光 / 白光将尽 VFX

## 持有白光

- `LastWhiteLightPower.AfterApplied` 创建一次角色专属光晕，重复应用不叠加视觉节点。
- 白色呼吸光、银白细环、缓慢升起的星屑，位于官方 `BackCombatVfxContainer`，在角色背后，不覆盖人物或 HUD。
- 随角色位置与战斗镜头缩放，移除状态、死亡、战斗结束后 0.25 秒淡出；读档时由 `NCreature._Ready` 补回。
- 白光临时层数消失后，白光将尽仍维持光晕，直到下一回合的爆发。

## 白光将尽触发

1. 0–0.36 秒：光环内缩，星屑向中心聚集，形成明亮星核。
2. 0.36 秒：白光超新星释放，双层冲击环、放射光束与碎星；播放官方重击音并使用尊重游戏设置的强震屏。
3. 0.50 秒：释放伤害结算等待。原有 `PowerCmd.Remove` 的短等待与蓄势并行，先展示爆发，再执行原伤害。
4. 余辉继续 1.0 秒，即使角色已死亡也不立即消失；场景退出则随场景清理。

正常模式以上述时间播放；快速模式视觉速度 ×1.6；瞬间、测试、非交互模式不创建特效或增加等待。低帧率时仍至少显示一次爆发帧，取消或场景退出不会遗留未完成等待。

## 玩法保持不变

这不是对敌人的新攻击。仍在下次自身回合开始时移除白光将尽，对持有者结算 `999999999`、`Unblockable | Unpowered` 的原始自身死亡伤害。复制出牌、卡牌费用、关键词、白光层数均未改变。新增流程中的战斗结束/战斗实例检查只防止异步视觉等待后的过期伤害。

场景：`nagato_white_light_aura.tscn`、`nagato_white_light_supernova.tscn`。全部为代码绘制的 Godot 2D 光效，无新贴图、战斗随机数或全局场景覆盖。
