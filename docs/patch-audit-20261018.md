# Patch 审查（2026-10-18）

范围为 `MainFile.Initialize` 注册的运行时补丁，不包含未编译的 `Deprecated` 代码，也不修改官方或 RitsuLib 源码。

## 结果

- Transpiler 审查后为 53 个补丁类型、65 个方法目标；临时覆甲合并新增一项局部 Postfix 后，目前为 54 个类型、66 个目标。
- Transpiler 方法由 4 个减少为 2 个，IL 改写目标由 6 个减少为 4 个。
- 不改变现有卡牌规则、抽牌结算顺序和多人同步方式。

## 本次替换

| 功能 | 原实现 | 当前实现 |
| --- | --- | --- |
| 封印牌自动打出时允许不可打出牌参与齐射 | 改写 `CardCmd.AutoPlay` 状态机中的关键词读取 | `Sealed.TryModifyKeywordsInCombat`，仅在该牌自己的封印自动打出期间移除全局计算结果中的不可打出；不改本地关键词，不跳过官方 `ShouldPlay` |
| 变牌后保留已知抽牌堆位置 | 改写 `CardCmd.Transform` 状态机中的 `GetReplacement` 调用 | 对 `CardTransformation.GetReplacement` 添加只读 Postfix，观察最终返回牌；不替换生成逻辑，不额外调用随机数 |

删除了 `NagatoSealedAutoplayPatch` 及其 UID、注册入口；变牌预览保留原有 `TransformPatch` 注册名称。

## 保留的 Transpiler

### 攀登新高山：`NagatoCardDrawnPatch`

目标为 `Hook.AfterCardDrawn` 的异步状态机，只改写 `AfterCardDrawnEarly`、`AfterCardDrawn` 两个分发调用。

需要在抽到的卡牌自身钩子所在位置立即追加该卡自己的效果，保留早期钩子、普通钩子、其他模型、卡牌能力组件与封印装填的相对顺序。

在整个分发函数结束后补调用会改变这个顺序；逐一补丁所有官方和其他模组卡牌的覆写方法会扩大补丁面，并引入继承调用重复计数、加载顺序等问题。当前未找到等价且更小的公开钩子，因此保留。

### 明镜止水：`NagatoOverflowDrawPatch`

目标为 `CardPileCmd.DrawInternal`、`CheckIfDrawIsPossibleAndShowThoughtBubbleIfNot`、`CombatManager.SetupPlayerTurn`。

需要同时保留真实手牌上限和原版抽牌流程：抽牌时允许越过满手检查，但溢出的牌进入弃牌堆，仍结算禁止抽牌、重洗、抽牌历史、抽到钩子和首回合抽牌规则。

全局增大手牌上限会改变生成牌、普通加入手牌等其他规则；用 Prefix 完整接管抽牌函数则会跳过原方法及其他模组在其内部的修改。因此保留这组局部 IL 改写，不复制整段官方抽牌实现。

满手溢出的牌仍可参与同一次抽牌的原版重洗。本次审查没有改动这条规则；与递归抽牌效果组合时的循环风险仍存在。

## 其他补丁逐组检查

| 注册分组 | 类型数 | 当前方式及保留原因 |
| --- | ---: | --- |
| 第四幕地图、入口、存档、房间与界面 | 18 | Prefix/Postfix/Finalizer；非虚地图接口、保存读取前规范化、原生场景初始化时点仍需适配；专属行为均按第四幕路线或模型判断 |
| 角色选择与攻击音效 | 3 | Prefix/Finalizer；只匹配长门事件路径，攻击玩家上下文在同步调用结束后恢复 |
| 卡框、抉择、挂球和白光视觉 | 4 | Postfix；在原版刷新后更新专属节点、恢复存档视觉，不接管游戏结算 |
| 角色选择转场 | 1 | 参数 Prefix 与 Task 完成后的恢复；保留原版取消、等待和输入阻塞流程 |
| 皮肤、共享进度和 Spine 初始化 | 10 | Prefix/Postfix/Finalizer；仅映射长门皮肤身份或专属动画，不改其他角色的身份与资源 |
| 激发记录、寄宿关键词和卡牌槽位 | 6 | Prefix/Postfix；保留钩子完成后装填、完整打牌包装结束后重新装填的时点，不能移到仅包围 `OnPlay` 的钩子 |
| 已知抽牌堆预览 | 7 | Prefix/Postfix；只记录当前本地长门可展示的信息，变牌观察已取消 IL 改写 |
| 覆甲规则 | 3 | 两项 Prefix 替换回合开始减层和回合结束触发；一项 Postfix 在原版移除覆甲结束后清理临时计数。普通失层由临时覆甲的原版能力变化钩子处理 |
| 抽到效果重复 | 1 | 保留上述局部分发 Transpiler |
| 满手溢出抽牌 | 1 | 保留上述局部抽牌 Transpiler |

减少 Transpiler 不等于保证所有模组都不会冲突。覆甲的全局规则替换，以及其他模组对相同抽牌分发位置的改写，仍需要双方机制兼容；没有为减少数量而新增整段抽牌或抽到钩子的替代实现。
