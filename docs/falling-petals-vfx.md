# 散华 / Falling Petals 命中特效

2026-10-21：原蓝卡散华已删除；流星群改名为金卡散华（`Cards/Rare/FallingPetals.cs`），沿用这套特效，原 X 费随机多段攻击、保留及抽到时获得能量的效果不变。

本卡专用场景：`res://NagatoSpire2/scenes/vfx/nagato_falling_petals.tscn`。

正常速度下，樱瓣在长门身边聚拢 0.24 秒，沿上扬弧线飞向本段攻击的随机目标 0.32 秒；花流到达时释放月白/樱粉五瓣光纹及短促金色光点，伤害随该帧结算。余下花瓣向外散开后缓缓下落，在 0.85 秒内消退。本段基础伤害只控制花瓣密度和适量震屏，不反过来改变伤害。

通过官方 `AttackCommand.WithHitVfxNode` 读取每段由官方选定的随机目标，再在 `BeforeDamage` 中播放花流。仍然只有一个官方多段攻击命令，不重选目标、不改变攻击钩子或活力扣层。场景及音效由卡牌 `ExtraRunAssetPaths` 预载，无需新增图片或修改全局 VFX。原蓝卡的临时能力扣层逻辑不恢复。

支持快速模式（动画 1.6 倍速度），瞬时/自动模拟/测试模式不等待画面。特效使用自身帧时钟，低帧率至少显示一次花流；中途目标死亡、战斗结束或节点退出会释放等待任务，不制造命中余光。成功命中后，即便目标死亡也保留短暂飘落余韵，场景自行释放。只读取目标位置，采用固定视觉噪声，不消耗战斗 RNG、不修改联机状态或全局时间缩放。震屏沿用玩家的官方设置。
